# Handwriting AI Studio ✍️✨

**Handwriting AI Studio** is a custom handwriting generation tool that allows you to trace your own alphabet samples and generate natural, realistic handwritten notes from any text prompt (such as responses from ChatGPT).

---

## 🌟 Key Features

* **Custom Character Tracing:** Trace letters, numbers, and punctuation directly on the canvas to build your personal digital handwriting font.
* **Granular Sizing & Adjustments:** Adjust letter-by-letter scales, default character spacing, word gaps, line bounce, ink thickness, and jitter for realistic variation.
* **Cross-Device Sync:** Sync your custom character glyphs and settings seamlessly across devices using Firebase authentication and cloud database storage.
* **Copy & Download Options:** Instantly copy transparent handwriting PNGs directly to your clipboard or download them as high-res images to use in Word, Docs, or graphics software.
* **Built-in Rate Limiting:** Daily usage caps built in for cloud resource management and fair usage.

---

## 🛠️ Tech Stack

* **Frontend:** Pure HTML5, CSS3, Vanilla JavaScript (HTML5 Canvas API)
* **Backend & Sync:** Firebase JS SDK v10 (Firebase Authentication & Firestore Database)
